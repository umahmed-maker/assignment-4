Assignment 3 – Secure Web Architecture

My website uses a secure architecture that separates the different parts of the application.

User
→
Frontend
→
Web Server
→
Application Layer
→
Database

Frontend

The frontend contains the pages, forms, buttons, and other features users interact with.

Security: Input validation helps prevent harmful input such as XSS.

Web Server

The web server receives browser requests and communicates with the application.

Security: HTTPS/TLS protects information while it travels between the browser and server.

Application Layer

The application processes requests, checks permissions, and communicates with the database.

Security: Requests are validated and users are limited to authorized actions.

Database

The database stores information needed by the application.

Security: Database access is restricted and passwords should be securely hashed instead of stored as plain text.

Authentication, Authorization, Encryption & Sessions

Authentication verifies a user's identity. Authorization determines what an authenticated user can access. Encryption protects information, while secure session management keeps track of logged-in users and expires inactive sessions.

Input Validation

Input is checked and safely handled to reduce threats such as SQL injection and Cross-Site Scripting (XSS).
